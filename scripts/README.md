# PowerShell Scripts

This folder contains PowerShell scripts used for configuring,
verifying and testing the ABC Technologies Windows Server 2022 lab.

## Active Directory
- Create-ABC-OU-Structure.ps1 — Creates the ABC Technologies OU structure.

## File Server
- Verify-ABC-FileServer.ps1 — Checks file server configuration.

## Group Policy
- Verify-Workstation-GPO.ps1 — Verifies workstation Group Policy.

## Validation
- Test-ABC-Infrastructure.ps1 — Runs infrastructure validation checks.

## Important
These scripts are provided for educational purposes.
Review and adapt them before running in another environment.
